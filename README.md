# AIMS-mini

Ứng dụng dòng lệnh (CLI) mô phỏng cửa hàng bán đĩa DVD, viết bằng Python thuần —
chỉ dùng thư viện chuẩn. Dự án mẫu cho bài thực hành môn IT3180
(Nhập môn Công nghệ phần mềm, Trường CNTT&TT – ĐHBK Hà Nội).

## Chạy chương trình

    python main.py

## Chạy kiểm thử

    python -m unittest discover -s tests -v

## Cấu trúc

- `dvd.py` – lớp `DigitalVideoDisc`
- `cart.py` – lớp `Cart`
- `main.py` – chương trình demo
